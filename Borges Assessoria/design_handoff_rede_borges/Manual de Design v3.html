01 · Fundamentos

O grande conceito

A Borges empresta dinheiro — mas o produto não é o ponto. O que a Borges constrói é uma rede privada de confiança que cresce só por indicação: pessoas responsáveis apadrinham pessoas responsáveis. O crédito é a consequência da confiança, nunca o contrário.

A frase que resume tudo

A Borges não vende crédito. A Borges constrói confiança. O crédito é apenas a forma como essa confiança se transforma em oportunidade.

A sensação a criar

Quando perguntarem “onde você conseguiu esse empréstimo?”, a resposta é “na Borges” — dita como quem diz “foi meu médico”, “foi meu advogado”. Não uma financeira. Não um banco. Um contato de confiança.

A promessa

Conseguir crédito deve ser uma experiência digna, respeitosa e segura — sem burocracia e sem que ninguém tenha vergonha de dizer que faz parte da Rede Borges.

04 · Direcionamento UI/UX

O sistema, em decisões de interface

Este capítulo traduz a marca em regras de interface, para o FinanceiroOp ficar alinhado sem depender de interpretação. Um desenvolvedor implementa a partir daqui.

01

Arquitetura visual

Densidade de terminal financeiro humanizado: nem landing com respiro infinito, nem planilha sufocada. Largura máxima de conteúdo 1200–1320px; grid de 12 colunas, gutters de 24px; sidebar fixa de navegação.

02

Hierarquia do Dashboard

3s: dinheiro em atraso + ação do dia (KPI grande, cor de marca). 10s: tendências da carteira. Consulta: o resto. KPIs têm tamanhos diferentes — nunca uma grade uniforme.

03

Tabelas financeiras

O coração do sistema. Números à direita, tabular-nums, linha de 44–48px para varredura, zebra sutil, agrupamento por cliente. Atraso sinalizado por tint na célula de data + pill — nunca a linha inteira vermelha.

04

Sistema de status

Pill com tint + texto por padrão; cor cheia só no selo de destaque de um registro; texto puro para status neutro/histórico. Máximo 3 cores de status simultâneas numa tabela.

05

Fluxos críticos

Registrar pagamento ≤ 2 passos; criar contrato ≤ 4. Pagamento é confirmação otimista com desfazer; baixa/exclusão exige confirmação explícita. Um pagamento recebido é vitória — reconhecimento visual sutil (selo verde + Linha de Confiança), não toast genérico.

06

Estados do sistema

Vazio nunca é tela branca — diz o próximo passo. Carregamento é skeleton na estrutura real, não spinner solto. Erro diz como resolver, perto do problema.

07

Microinterações

150–300ms em cor / opacidade / transform. Nunca animação que desloca layout. prefers-reduced-motion respeitado. Motion confirma ação — nunca decora. (Só documentamos o que será implementado de verdade.)

08

Iconografia funcional

UM set de ícones SVG, stroke de 1.75px, grid de 24px, tamanhos fixos (16/20/24). Nunca emoji como ícone; nunca mistura de sets.

09

Interação impecável

Todo clicável tem cursor:pointer e hover; alvos de toque ≥ 44px; foco visível para teclado; botão desabilita durante operação assíncrona.

10

Ergonomia claro/escuro

O claro é o mais traído em dashboards. Os dois modos são especificados com o mesmo rigor e testados nos dois antes de qualquer entrega — sem cinza ilegível, borda invisível ou vidro transparente demais.

07 · Governança

Governança & checklist

Este manual é a fonte única. Quando falta algo, não se inventa — propõe-se uma adição. Foi a ausência dessa regra que matou o sistema anterior.

Quando falta um token
  1. Confirme que a cor realmente não existe na tabela (2.2).
  2. Verifique se um token semântico existente cobre o caso.
  3. Se ainda faltar, proponha a adição ao manual — com nome, par claro/escuro e contraste — antes de usar.
  4. Nunca hardcode um hex “provisório”. Provisório vira permanente.
Como o manual evolui

Mudança de token é versionada aqui e propagada a todas as superfícies de uma vez. Um valor, um lugar. Se três documentos discordam de uma cor, este arquivo vence — os outros se corrigem.

Regra de ouro: nunca digite um hex de memória. Sempre copie da tabela.

7.2

Justificativas das decisões centrais

Cada escolha amarrada ao grande conceito — “a Borges não vende crédito, constrói confiança” — e aos seis valores.

PALETA

Mantive os três verdes, mas aqueci os neutros para marfim — o “papel” de uma instituição em que se confia, não o cinza de um banco. Verde é Confiança e raiz; o marfim traz o Respeito e o Atendimento humano. Uma paleta contida executada com precisão vale mais que dez efeitos da moda.

TIPOGRAFIA

A serif Newsreader nos títulos dá à marca a dignidade de um documento que se guarda — serve ao orgulho de pertencer e ao Compromisso. Helvetica com algarismos tabulares mantém o dinheiro preciso (dado é protagonista). Não é Inter por inércia: é serif por decisão, amarrada ao “teria orgulho de mostrar?”.

FORMA

O símbolo de módulos sobrepostos vira duas pessoas se conectando — o padrinho e quem ele traz. A grade base-4 diz Simplicidade e Responsabilidade: tudo se alinha, nada é arbitrário.

ASSINATURA

A Linha de Confiança — nós ligados por um fio contínuo — é a rede desenhada: cada membro é um nó, cada indicação estende a linha. Aparece no certificado, no rodapé dos PDFs, no header do app e como divisor. É a marca sem o logo; nenhum template tem essa linha.

LINGUAGEM

O tom sério-humano protege a Confiança: firme no fato sem a frieza de banco nem a agressão de cobrador. Cada mensagem trata a pessoa como alguém que a rede respeita — e convida à indicação sem simular escala falsa.

A confiança vira oportunidade.
